# Support

## How to get help

1. **Documentation** — start at [docs/index.md](docs/index.md) and the [getting started guide](docs/getting-started/quick-start.md).
2. **Troubleshooting** — [docs/troubleshooting/common-errors.md](docs/troubleshooting/common-errors.md) and the [FAQ](docs/troubleshooting/faq.md).
3. **Questions** — open a [GitHub Discussion](https://github.com/KKORA/koras-api-client/discussions) (preferred) or an issue with the question template.
4. **Bugs / feature requests** — use the [issue templates](https://github.com/KKORA/koras-api-client/issues/new/choose).
5. **Security issues** — see [SECURITY.md](SECURITY.md); never a public issue.

## Support expectations

This is an open-source project maintained by Koras Technologies. Issues are triaged weekly; there is no commercial SLA. PRs with failing-test reproductions get the fastest turnaround.
